데이터와 학습 코드

입력: 행동 직전 카메라 3개 + 로봇 상태 + 컵 놓기 지시문. 타깃: 성공 구간에서 실제 실행한 12D 액션, 50-step 청크와 유효 구간 마스크. 버튼 동작과 실패 실행은 학습 타깃에서 제외합니다.
